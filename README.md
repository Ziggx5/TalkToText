Talk-To-Text 🎤

TalkToText is a simple desktop app, that converts speech to text in real time using **Vosk** speech recognition engine and CustomTkinter for the UI.

<img width="580" height="483" alt="image" src="https://github.com/user-attachments/assets/04e89a35-5f58-4a46-976a-d37bed4342ac" />

---
✨ Features
- 🎙 **Offline Speech-To-Text** (Vosk)
- 💻 **Simple and minimalistic UI**
- 🔊 **Input selection**
- ⏱️ **Elapsed time counter**
- 📋 **Copy to clipboard**
- 💾 **Save files**
- ✨ **Clean and stable UI**
---

🚀 Installation
1. Go to **Releases**.
2. Download the lastest `.zip`.
3. Extract it anywhere you like.
4. Run the application (`Talk-To-Text.exe`)

🛠️ Technologies/libraries Used
- Python
- Vosk (speech recognition engine)
- Os
- Sys
- Pillow
- CustomTkinter
- PyAudio
- Threading
- Time
- Json
